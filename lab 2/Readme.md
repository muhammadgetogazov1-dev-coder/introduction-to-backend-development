Цель работы
Освоить обработку HTTP-методов (GET, POST, PUT, DELETE) в Express. Научиться реализовывать CRUD-операции над коллекцией объектов, хранящейся в памяти сервера, а также возвращать корректные HTTP-коды ответов (200, 201, 204, 400, 404).

Теоретическое обоснование
CRUD — акроним четырёх базовых операций над данными:

Операция	Расшифровка	HTTP-метод	SQL-аналог
Create	Создание	POST	INSERT
Read	Чтение	GET	SELECT
Update	Обновление	PUT / PATCH	UPDATE
Delete	Удаление	DELETE	DELETE
HTTP-методы:

GET — получение данных, идемпотентен, безопасен.

POST — создание, не идемпотентен.

PUT — полное обновление, идемпотентен.

PATCH — частичное обновление.

DELETE — удаление, идемпотентен.

Коды состояния:

Код	Название	Когда используется
200	OK	Успешный GET, PUT
201	Created	Успешный POST
204	No Content	Успешный DELETE (без тела)
400	Bad Request	Ошибка валидации
404	Not Found	Ресурс не найден
500	Internal Server Error	Ошибка на сервере
Выполнение практического примера
Описание кода app.js
Сервер на Node.js + Express.js хранит данные в памяти (массив students). Подключён middleware express.json() для парсинга JSON. Функция validate() проверяет поля: name и group — непустые строки, course — 1–6, avg_grade — 0–5.

Реализованы 5 эндпоинтов: GET /items (список + поиск + сортировка + пагинация), GET /items/:id, POST /items (201/400), PUT /items/:id (200/400/404), DELETE /items/:id (204/404). Данные сбрасываются при перезапуске сервера.

Рисунок 2 — CRUD-эндпоинты:

GET /items/:id — находит студента по id через find(). Если не найден — 404, если найден — 200.

POST /items — создаёт нового студента, валидирует тело через validate(). При ошибке — 400 с массивом errors. При успехе — 201 Created.

PUT /items/:id — полное обновление. Ищет индекс через findIndex(). Если не найден — 404, при ошибке валидации — 400, при успехе — 200.

DELETE /items/:id — удаление. Ищет индекс через findIndex(). Если не найден — 404, при успехе — 204 No Content.

Ответы на контрольные вопросы
1. Что такое CRUD? Расшифруйте каждую букву.
CRUD — Create (создание), Read (чтение), Update (обновление), Delete (удаление).

2. Какие HTTP-методы соответствуют операциям CRUD?
POST — Create, GET — Read, PUT/PATCH — Update, DELETE — Delete.

3. Что такое идемпотентность HTTP-методов? Какие методы идемпотентны?
Идемпотентность — повторный запрос даёт тот же результат. Идемпотентны: GET, PUT, DELETE.

4. Какой код ответа возвращается при успешном создании ресурса (POST)?
201 Created.

5. Какой код ответа возвращается при успешном удалении ресурса?
204 No Content (или 200 OK).

6. Что такое middleware в Express? Для чего используется express.json()?
Middleware — функция между запросом и ответом. express.json() парсит JSON из тела в req.body.

7. Как получить параметры из тела POST-запроса в Express?
Через req.body (после app.use(express.json())).

8. Как получить параметр из URL (например, ID)?
Через req.params.id.

9. Как найти элемент в массиве по ID?
Через items.find(i => i.id === id).

10. Какой код ответа возвращается, если ресурс не найден?
404 Not Found.

11. Как отправить JSON-ответ в Express?
Через res.json(data).

12. Как вернуть статус-код 201 в Express?
Через res.status(201).json(data).

13. Что произойдёт с данными в памяти при перезапуске сервера?
Сбросятся к начальному состоянию.

14. Как добавить новый элемент в массив?
Через students.push(newItem).

15. Как удалить элемент из массива?
Через students.splice(index, 1) или students.filter(...).
